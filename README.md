# 🌤️ Weather & City Explorer Dashboard

A premium web-based weather dashboard that provides real-time weather updates along with an interactive city exploration experience.

---

## 🚀 Live Demo

🔗 https://weather-city-explorer2005.netlify.app

---
## ✨ Features

- 🌡️ Real-time weather updates using WeatherAPI  
- 📅 Yesterday, Today & Tomorrow forecast  
- 🏙️ City image slider with famous places  
- 🗺️ Explore Indian cities by state  
- ⭐ Add & manage favorite cities  
- 🕘 Recent search history with delete & clear option  
- 🎤 Voice search for city input  
- 📍 Current location weather detection  
- 🌗 Dark / Light mode toggle
- 🌡️ Temperature unit toggle (°C / °F)  
- 💬 Dynamic weather-based quotes  
- ⏳ Loading animation for better UX

- HTML

- WeatherAPI
